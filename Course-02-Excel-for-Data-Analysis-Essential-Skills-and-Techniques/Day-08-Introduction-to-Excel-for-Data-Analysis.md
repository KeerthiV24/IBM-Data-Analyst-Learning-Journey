### 12. Referencing Data in Formulas

Learned about three types of cell references:

**Relative Reference**
- Example: `A3`
- Changes automatically when a formula is copied to another cell.

**Absolute Reference**
- Example: `$A$3`
- Remains fixed when a formula is copied.

**Mixed Reference**
- Examples: `$A3` and `A$3`
- Keeps either the column or row fixed while the other can change.
