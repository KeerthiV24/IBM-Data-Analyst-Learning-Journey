# Day 03 – Data Repositories and Relational Databases

**Date:** 11 November 2026  
**Course:** IBM Data Analyst Professional Certificate

## 📚 Topics Covered

### 1. Overview of Data Repositories
- A data repository is a place where collected data is stored, organized, and managed.
- Data repositories support reporting and data analysis.
- Common types include databases, data warehouses, and data lakes.

### 2. Database Management Systems (DBMS)
- A database stores and organizes data.
- A DBMS is software used to create, manage, store, and retrieve data.
- Key functions include data storage, security, querying, transaction management, and backup.

### 3. Types of Databases
- **Relational Databases:** Store data in tables with rows and columns.
- **Non-Relational Databases:** Support flexible data structures and different data formats.

### 4. Relational Database Management Systems (RDBMS)
- Organize data into related tables.
- Use primary keys and foreign keys to establish relationships.
- Use SQL (Structured Query Language) to query and manage data.
- Examples: MySQL, PostgreSQL, IBM Db2, and Microsoft SQL Server.

### 5. Advantages of RDBMS
- Reduces data redundancy.
- Maintains data accuracy and consistency.
- Supports relationships between tables.
- Provides security and access control.
- Supports structured queries using SQL.

### 6. Limitations of RDBMS
- Not always suitable for semi-structured and unstructured data.
- Scaling across multiple database systems can be challenging.
- Large data volumes may require additional storage and performance optimization.

### 7. Data Warehouses and ETL
- A data warehouse stores data for reporting and analysis.
- ETL stands for Extract, Transform, and Load.
- ETL combines data from different sources, transforms it, and loads it into a target system.

### 8. OLTP and OLAP
- **OLTP (Online Transaction Processing):** Handles day-to-day transactions.
- **OLAP (Online Analytical Processing):** Supports data analysis and reporting.

## 💡 Key Takeaways
- Data repositories help organize and manage data.
- DBMS and RDBMS are important for storing and retrieving data.
- SQL is used to query relational databases.
- Data warehouses support analytical workloads.
- ETL helps prepare data for analysis.
