## 🎯 Topics Covered

### 1. Python Data Types

Learned about the basic Python data types:

- **Integer (`int`):** Stores whole numbers.
- **Float (`float`):** Stores decimal numbers.
- **String (`str`):** Stores text inside quotes.
- **Boolean (`bool`):** Stores `True` or `False`.

Also learned about type conversion, such as converting integers into strings using `str()`.

### 2. Expressions and Variables

- Expressions perform mathematical operations using operators.
- Variables store values for later use.
- Practiced arithmetic operators such as `+`, `-`, `*` and `/`.
- Used variables in calculations and expressions.

### 3. String Indexing and Slicing

- A string is a sequence of characters.
- Learned positive and negative indexing.
- Practiced accessing individual characters using indexes.
- Used slicing to extract portions of a string.

### 4. String Concatenation and Immutability

- String concatenation combines two or more strings using `+`.
- Learned that strings are immutable, meaning their original value cannot be changed directly.
- Practiced creating new strings using concatenation.

### 5. Escape Sequences

Learned how to use special characters inside strings:

- `\n` – New line
- `\t` – Tab space
- `\\` – Backslash
- `\'` – Single quote

### 6. Python String Methods

Practiced useful string methods:

- `upper()` – Converts text to uppercase.
- `replace()` – Replaces a specified part of a string.
- `find()` – Finds the position of a substring.

### 7. String Formatting

Explored different ways to format strings in Python:

- **f-strings:** Insert variables directly into strings.
- **format():** Use placeholders `{}` to insert values.
- **% operator:** An older method of formatting strings.

### 8. Raw Strings

- Learned about raw strings using the `r` prefix.
- Raw strings are useful when handling text containing backslashes and escape characters.

## 💡 Key Learning Outcomes

- Understood basic Python data types and type conversion.
- Learned how to work with variables and expressions.
- Practiced string indexing and slicing.
- Understood string concatenation and immutability.
- Explored important string methods and formatting techniques.
- Learned how to use escape sequences and raw strings.
