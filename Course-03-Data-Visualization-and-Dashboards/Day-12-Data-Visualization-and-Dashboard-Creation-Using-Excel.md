# Day 12 – Data Visualization and Dashboard Creation Using Excel

**Date:** 22 November 2026  
**Course:** IBM Data Analyst Professional Certificate
  
## 📚 Topics Covered

### 1. Using Excel PivotChart Features
- PivotCharts are used to visualize data from Pivot Tables.
- They work similarly to standard Excel charts.
- The source data is connected to a Pivot Table.     
- Useful for presenting complex data in a simple visual format.

### 2. Understanding Different Chart Types

**Area Chart**
- Displays data points connected by straight lines.
- Shows a filled area below the connected lines.
- Helps identify trends over time.
- Can display positive and negative values.

**Column Chart**
- Compares values across different categories using vertical bars.
- Categories are displayed on the horizontal axis.
- Values are displayed on the vertical axis.
- Useful for comparing sales, products, and business performance.

### 3. Creating Treemaps, Scatter Charts and Histograms

**Treemap**
- Compares values across hierarchical levels.
- Displays proportions using rectangles.
- Useful for presenting large amounts of hierarchical data.
- Colors and sizes represent different data categories.

**Scatter Chart**
- Compares two sets of numerical values.
- Shows relationships between two variables.
- Uses X-axis and Y-axis values to represent individual data points.
- Useful for identifying patterns and relationships.

**Histogram**
- Displays the distribution of numerical data grouped into bins.
- Helps understand how frequently values occur within different ranges.
- Looks similar to a bar chart but has a different purpose.
- Bar charts compare categories, while histograms show data distribution.

### 4. Other Excel Visualization Features
- Map Charts.
- Sparklines.
- Radar Charts.
- Funnel Charts.
- Stock Charts.

These charts help present different types of data in meaningful visual formats.

### 5. Introduction to Dashboards

- A dashboard presents important information in one place.
- It combines charts, tables, and other visual elements.
- Dashboards help users understand business performance.
- They can include interactive features such as filters, slicers, timelines, and map charts.
- Dashboards help monitor important business metrics and KPIs.

### 6. Benefits of Dashboards
- Provides useful insights from data.
- Helps identify trends and patterns.
- Offers an interactive experience using filters.
- Updates dynamically when the underlying data changes.
- Provides a centralized view of important business information.
- Helps support better business decisions.

### 7. Data Analyst Skills and Tools
- Basic spreadsheet applications such as Microsoft Excel and Google Sheets.
- Advanced data analysis and visualization tools.
- Python libraries and Jupyter Notebook.
- RStudio and Shiny.
- Tableau and IBM Cognos Analytics.

### 8. Using Dashboards to Present Data Results
- Present information clearly and accurately.
- Keep dashboard content specific and concise.
- Highlight important findings and insights.
- Focus on the information the audience needs.

### 9. Creating a Simple Dashboard Using Excel

**Basic Steps:**
1. Collect and organize the data.
2. Verify that the data is clean and error-free.
3. Remove blank rows and columns.
4. Format the data as an Excel table.
5. Create Pivot Tables.
6. Create visualizations such as charts and maps.
7. Add interactive elements such as slicers.
8. Arrange the visualizations to create a dashboard.

## 💡 Key Takeaways
- PivotCharts help visualize data from Pivot Tables.
- Different chart types are useful for different data analysis purposes.
- Treemaps display hierarchical data.
- Scatter charts help identify relationships between numerical variables.
- Histograms show the distribution of data.
- Dashboards combine charts and visualizations in one place.
- Interactive dashboards help users explore data and identify insights.
- Excel can be used to create simple and useful business dashboards.
