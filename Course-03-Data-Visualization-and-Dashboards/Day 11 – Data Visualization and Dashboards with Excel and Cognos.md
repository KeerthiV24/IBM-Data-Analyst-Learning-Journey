### 6. Introduction to Pivot Tables in Excel

**What is a Pivot Table?**

A Pivot Table is an Excel feature used to summarize, organize and analyze large amounts of data quickly.

**Benefits of Pivot Tables:**
- Summarize and analyze data easily.
- Identify trends and patterns.
- Compare different categories.
- Update summaries when source data changes.
- Generate useful insights from data.

**Pivot Table Checklist:**
- Convert data into a table.
- Ensure column headings are correct.
- Remove blank rows, columns and cells.
- Ensure values are properly formatted.
- Check that data types are consistent.
