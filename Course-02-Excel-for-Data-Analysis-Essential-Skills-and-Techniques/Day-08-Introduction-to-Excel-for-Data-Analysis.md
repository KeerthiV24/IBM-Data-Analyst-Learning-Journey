# Day 08 – Introduction to Excel for Data Analysis

**Date:** 15 November 2026  
**Course:** IBM Data Analyst Professional Certificate

## 📚 Topics Covered

### 1. Introduction to Spreadsheets
- A spreadsheet is used to organize, store, calculate, and analyze data.
- **Microsoft Excel:** Commonly used spreadsheet application and part of Microsoft Office. It also has a web-based version.
- **Google Sheets:** Free web-based application that works with a Google account and integrates with other Google apps.
- **LibreOffice Calc:** Free and open-source desktop spreadsheet application.
- Other applications include Zoho Sheet, OpenOffice Calc, Quip, Smartsheet, and Apple Numbers.

### 2. Advantages of Using Spreadsheets
- Perform accurate calculations.
- Automate calculations.
- Organize and arrange data.
- Format, filter, and sort data.
- Edit, undo, and review data.
- Analyze data.
- Create charts, graphs, and reports.

### 3. Common Business Uses of Spreadsheets
- Data entry and storage.
- Comparing large datasets.
- Modelling and planning.
- Creating charts and identifying trends.
- Tracking business processes and sales.
- Financial forecasting.
- Statistical analysis.
- Profit and loss accounting.
- Budgeting and auditing.
- Payroll, tax reporting, invoicing, and scheduling.

### 4. How Data Analysts Use Spreadsheets
Data analysts use spreadsheets for four important activities:
- Collecting data.
- Cleaning data.
- Analyzing data.
- Visualizing data.

### 6. Spreadsheet Basics – Part 2
- Understanding the Excel Ribbon and menus.
- Navigating through worksheets.
- Selecting multiple cells and columns.
- Using keyboard shortcuts to move around the spreadsheet.

**Useful Keyboard Shortcuts:**

| Shortcut | Purpose |
|---|---|
| Ctrl + Home | Move to the first cell |
| Ctrl + End | Move to the last used cell |
| Ctrl + ↓ | Move to the end of a data region |
| Ctrl + ↑ | Move to the beginning of a data region |
| Shift + Arrow Keys | Select multiple cells |
| Ctrl + A | Select all data |

### 7. Using Spreadsheets as a Data Analysis Tool

**Advantages:**
- View data clearly in tables.
- Easily enter and update data.
- Perform calculations and financial analysis.
- Create charts, graphs, and pivot tables.
- Filter and sort data.
- Generate reports.
- Useful for simple analysis and datasets with up to around 20,000 lines, as mentioned in the learning notes.

**Limitations:**
- It can be difficult to reproduce the same analysis steps.
- It is difficult to track which steps have been performed on a dataset.

### 10. Basics of Formulas
- A formula starts with the `=` sign.
- Cell references are used to access values.
- Mathematical operators are used for calculations.
- Constants can be included in formulas.

**Example:** `=SUM(B5+20)`

### 11. Introduction to Functions
- Understanding spreadsheet functions.
- Learning how functions help perform calculations.
- Introduction to the function library.

### 12. Referencing Data in Formulas

Learned about three types of cell references:

- **Relative Reference:** Example: `A3`. Changes automatically when a formula is copied to another cell.
- **Absolute Reference:** Example: `$A$3`. Remains fixed when a formula is copied.
- **Mixed Reference:** Examples: `$A3` and `A$3`. Keeps either the column or row fixed while the other can change.

## 💡 Key Takeaways
- Spreadsheets are important tools for organizing and analyzing data.
- Microsoft Excel and Google Sheets are commonly used spreadsheet applications.
- Excel helps with data entry, calculations, formatting, and visualization.
- Keyboard shortcuts make spreadsheet navigation easier.
- Formulas and functions help perform calculations.
- Relative, absolute, and mixed references are important when copying formulas.
