## 2\. Different Data Sources

Data analysts collect information from different sources to analyse business problems and make decisions.

### Common Data Sources

1. Relational Databases
2. Flat Files and Text Files
3. XML and JSON Files
4. Spreadsheets
5. Cloud Storage
6. APIs and Web Sources

### Relational Databases

- Store data in tables.
- Tables contain rows and columns.
- Data can be retrieved using SQL.
- Examples: MySQL, PostgreSQL and IBM Db2.

### Flat Files

- Store data in plain text or tabular formats.
- Common examples include CSV and TSV.
- Useful for sharing and transferring datasets.

## 3\. Understanding File Formats

### CSV – Comma-Separated Values

- Stores data in a tabular format.
- Values are separated by commas.
- Commonly used for data exchange and analysis.
- Can be opened using Excel and Python.

### TSV – Tab-Separated Values

- Similar to CSV.
- Uses tabs to separate values instead of commas.

### XML – Extensible Markup Language

- Stores data using tags.
- Useful for exchanging structured information.
- Supports hierarchical data.

### JSON – JavaScript Object Notation

- Stores data using key-value pairs.
- Commonly used in APIs and web applications.
- Easy to read and exchange between systems.

## 4\. Programming Languages Used in Data Analytics

### Python

- Easy-to-learn programming language.
- Used for data cleaning and analysis.
- Supports libraries such as Pandas and NumPy.
- Useful for automation and visualization.

### SQL

- Used to communicate with relational databases.
- Helps retrieve, filter and manipulate data.
- Important for database querying.

### R

- Used for statistical analysis.
- Supports data visualization.
- Useful for statistical computing.

### Shell Scripting

- Used to automate operating system tasks.
- Helps manage files and execute commands.

## 5\. Other Tools and Technologies

- APIs – Accessing and exchanging data between applications.

## 6\. Key Takeaways

- Data can come from different sources and formats.
- CSV and TSV are commonly used for tabular data.
- XML and JSON are useful for exchanging structured information.
- SQL is essential for working with relational databases.
- Python helps with data cleaning, analysis and automation.
- Different tools serve different purposes in the data analytics process.

## 7\. Interview Preparation

**Q1. What is CSV?**

CSV stands for Comma-Separated Values. It is a file format used to store tabular data where values are separated by commas.

**Q2. What is the difference between CSV and TSV?**

CSV uses commas as separators, whereas TSV uses tab characters.

**Q3. What is JSON?**

JSON is a lightweight data exchange format that stores information using key-value pairs.

**Q4. What is XML?**

XML is a markup language used to store and exchange structured data using tags.

**Q5. Why is SQL important for data analysts?**

SQL helps analysts retrieve, filter, organize and analyse information stored in relational databases.

**Q6. Why is Python used in data analytics?**

Python is used for data cleaning, manipulation, analysis, visualization and automation.
