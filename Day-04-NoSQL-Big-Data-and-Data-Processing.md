# Day 04 – NoSQL, Big Data and Data Processing

**Date:** 11 November 2026  
**Course:** IBM Data Analyst Professional Certificate

## 📚 Topics Covered

### 1. NoSQL Databases
- NoSQL means non-relational databases.
- Stores data using flexible data models.
- Supports structured, semi-structured, and unstructured data.
- Useful for big data and high-volume applications.
- Offers scalability and flexibility.

### 2. Types of NoSQL Databases

**Key-Value Database**
- Stores data as key-value pairs.
- Useful for caching and real-time applications.
- Examples: Redis, Memcached, DynamoDB.

**Document Database**
- Stores data in individual documents.
- Supports flexible data structures.
- Examples: MongoDB, CouchDB.

**Column-Based Database**
- Stores data in column groups.
- Suitable for large datasets and time-series data.
- Examples: Cassandra, Apache HBase.

**Graph-Based Database**
- Stores data as nodes and relationships.
- Useful for social networks and recommendation systems.
- Examples: Neo4j, Amazon Neptune.

### 3. Advantages of NoSQL
- Handles large volumes of data.
- Supports distributed storage.
- Provides easy scalability.
- Offers flexible data structures.
- Supports high availability.

### 4. Relational vs Non-Relational Databases
- Relational databases use tables with fixed schemas.
- NoSQL databases support flexible data structures.
- Relational databases commonly use SQL.
- NoSQL databases use different query methods depending on the database.

### 5. Data Repositories
**Data Warehouse**
- Stores organized data for reporting and analysis.
- Acts as a central source of information.

**Data Mart**
- A smaller part of a data warehouse.
- Focuses on a specific business area.

**Data Lake**
- Stores large amounts of raw data.
- Supports different data formats.
- Useful for advanced analytics.

### 6. ETL Process
ETL stands for Extract, Transform, and Load.

- **Extract:** Collect data from different sources.
- **Transform:** Clean, standardize, and prepare data.
- **Load:** Move processed data into a data repository.

Data processing methods:
- Batch processing: Processes data at scheduled intervals.
- Stream processing: Processes data continuously or in real time.

### 7. Data Pipelines
- Move data from one system to another.
- Include extraction, transformation, and loading.
- Support both batch and streaming data.

### 8. Foundations of Big Data
Big Data refers to large and complex datasets that require special tools for processing.

**5 Vs of Big Data:**
1. Volume – Amount of data.
2. Velocity – Speed at which data is generated.
3. Variety – Different types of data.
4. Veracity – Accuracy and reliability of data.
5. Value – Useful insights gained from data.

### 9. Big Data Processing Tools

**Hadoop**
- Supports distributed storage and processing.
- Works across clusters of computers.
- Provides scalability and fault tolerance.

**HDFS (Hadoop Distributed File System)**
- Stores large files across multiple computers.
- Splits files into blocks.
- Replicates data to help prevent data loss.

**Hive**
- Open-source data warehouse software.
- Helps query and manage large datasets.
- Useful for reporting and data analysis.

**Apache Spark**
- A general-purpose data processing engine.
- Supports large-scale data processing.
- Used for analytics, streaming, machine learning, and ETL.

## 💡 Key Takeaways
- NoSQL databases provide flexible data storage.
- Data warehouses and data lakes support analytics.
- ETL prepares data for analysis.
- Big Data is explained through the 5 Vs.
- Hadoop, Hive, and Spark are important Big Data technologies.
