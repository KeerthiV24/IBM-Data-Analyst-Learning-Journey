# Day 05 – Gathering, Importing and Cleaning Data

**Date:** 14 November 2026  
**Course:** IBM Data Analyst Professional Certificate

## 📚 Topics Covered

### 1. Gathering and Importing Data
- Gathering data from different sources such as databases, websites, social media, and data exchange platforms.
- Importing collected data into different types of data repositories.
- Choosing data sources based on specific data requirements.

### 2. Using SQL Queries to Extract Data
- SQL is a query language used to retrieve information from relational databases.
- SQL queries help specify:
  - What data needs to be retrieved.
  - Which table contains the data.
  - Which records match specific conditions.
  - How results should be grouped and sorted.
  - How many results should be returned.

### 3. Application Programming Interfaces (APIs)
- APIs help applications access and retrieve data from different sources.
- They connect applications with databases, web services, and data marketplaces.
- APIs can also be used for data validation.

### 4. Extracting Data from the Web
**Web Scraping (Screen Scraping and Web Harvesting)**
- Used to collect specific information from web pages.
- Can extract text, images, videos, and product information.
- RSS feeds help capture updated information from websites and online sources.

### 5. Other Data Sources
- **Data Streams:** Continuous data generated by sources such as IoT devices, GPS applications, and social media.
- **Data Exchange Platforms:** Allow data providers and consumers to exchange data using defined standards and protocols.
- Other sources include consulting firms, research organizations, and market research agencies.

Examples of data exchange platforms mentioned in my notes:
- AWS Data Exchange
- Crunchbase
- Jotform
- Snowflake

### 6. Types of Data to Import

**Structured Data**
- Organized data with a well-defined structure.
- Common sources include spreadsheets, online forms, and relational databases.

**Semi-Structured Data**
- Data that does not follow a strict table structure.
- Examples include XML and JSON files.

**Unstructured Data**
- Data without a predefined structure.
- Examples include web pages, images, videos, documents, and social media content.

### 7. Data Wrangling
- Also known as data munging.
- The process of exploring, transforming, validating, and preparing raw data.
- Makes data reliable and meaningful for analysis.

**Four Data Wrangling Phases:**

1. **Discovery:** Understand the data and identify cleaning requirements.
2. **Transformation:** Structure, clean, normalize, and enrich data.
3. **Validation:** Check data quality, consistency, and accuracy.
4. **Publishing:** Deliver prepared data for further analysis.

### 8. Tools for Data Wrangling
- Excel Power Query / Spreadsheet
- OpenRefine
- Google Dataprep
- IBM Watson Studio Refinery
- Trifacta Wrangler
- Python
- R

**Python Libraries**

- Dplyr: A data-wrangling library in R.

### 9. Data Cleaning
- Data cleaning improves the quality and reliability of data.
- Poor-quality data can lead to incorrect conclusions and ineffective decisions.

**Common Data Quality Issues:**
- Missing values
- Duplicate records
- Incorrect data
- Inconsistent records
- Irrelevant data
- Incorrect data formats
- Outliers
- Syntax errors

### 10. Data Cleaning Workflow

1. **Inspection:** Identify errors and understand the data.
2. **Cleaning:** Correct issues and improve data quality.
3. **Verification:** Check whether the cleaned data is accurate and reliable.

**Important Cleaning Activities:**
- Data profiling: Understand data structure, content, and relationships.
- Data visualization: Examine data to identify patterns and issues.
- Missing values: Remove records or use suitable methods to fill missing information.
- Duplicate data: Identify and remove repeated records.
- Irrelevant data: Remove information not related to the use case.
- Data type conversion: Ensure values use the correct data types.
- Standardization: Make date, time, and measurement formats consistent.
- Outlier checking: Examine unusual values.
- Syntax correction: Fix issues such as extra spaces and incorrect formats.

### 11. Data Preparation and Reliability
- Data preparation is an important part of a Data Analyst's work.
- Data must be accurate and relevant before analysis.
- No dataset is perfect, so it is important to understand potential data problems.
- Summary statistics help check whether data is consistent with expectations.
- Basic data integrity checks should be completed before analysis.

## 💡 Key Takeaways
- Data can be collected from databases, APIs, websites, and data streams.
- SQL queries help retrieve information from databases.
- APIs and web scraping are useful data collection methods.
- Data wrangling prepares raw data for analysis.
- Data cleaning improves data accuracy and reliability.
- Python, R, Excel, and other tools support data preparation.
